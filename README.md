# Calorie Tracker

## About the Project

This is a simple Calorie Tracker made with PHP. The program runs in the terminal.

I created this project to keep track of the food I eat and how many calories it has.

## Features

- Add food
- Enter the calories for each food
- Show all added food
- Show the total amount of calories
- Choose what to do in the menu
- Exit the program

## How to Use

When you start the program, a menu appears in the terminal.

You can choose what you want to do by entering a number.

If you want to add food, you enter the name and the calories. The program saves the information and adds the calories together.
